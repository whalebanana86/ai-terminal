## 요구사항

- 위쪽 저장소 탭마다, 그 저장소(모든 워크트리)에서 지금 실행 중인 AI 에이전트(Claude·Codex)가 있으면 표시한다.
  - 센다: 앱 터미널에서 띄운 실행 + 앱 밖(다른 터미널·앱)에서 띄운 실행. 같은 실행을 두 번 세지 않는다.
  - 어느 저장소의 것인지: 연결된 세션의 저장소(상위 폴더에서 시작해 하위 저장소에서 일한 세션도 그 저장소). 세션을 모르면 실행 폴더가 저장소 워크트리 안인지로.
- Claude 는 스스로 적는 상태(`~/.claude/sessions/<pid>.json` 의 status)로 나눠 보인다.
  - busy·shell → 일하는 중, waiting → 확인 필요(승인·질문 답을 기다림), idle → 대기 중.
  - Codex 는 상태를 남기지 않아 "실행 중"으로만(일하는지 알 수 없음).
  - 탭에는 가장 급한 하나만: 확인 필요 > 일하는 중 > 대기·실행 중. 마우스를 올리면 개수를 상태별로.
- 성능 원칙: 새 프로세스 띄우기·새 타이머 없음(이미 5초마다 도는 실행 감지 결과를 쓴다), 계속 도는 CSS 애니메이션 없음.

## 발견한 문제

- Codex 는 일하는 중인지 알 수 있는 기록이 없어 "실행 중"(초록 테두리)으로만 보인다. 앱 터미널 출력이 최근에 있었는지로 짐작할 수는 있지만, 오래 생각하는 동안은 출력이 없어 틀릴 수 있어 넣지 않았다.
- 실행 감지는 창이 보일 때만 5초마다 돈다(기존 동작). 그래서 표시는 최대 5초쯤 늦다.
- 상위 폴더(저장소 아님)에서 띄운 앱 밖 실행은, 세션 목록이 그 세션을 하위 저장소에 연결한 뒤에야 그 탭에 붙는다(단위 테스트로 확인, 실제 앱 시험에서는 기록 파일이 없어 확인 안 함).
