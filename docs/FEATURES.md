### Git (왼쪽)
| | 기능 | 검증 |
|---|---|---|
| ✅ | 로컬 저장소 추가(비공개 포함, git CLI 인증 그대로) | E2E A |
| ✅ | 워크트리 목록(경로·브랜치·HEAD·메인/링크·잠김·폴더 없음) | E2E A + 통합 테스트 |
| ✅ | 커밋 그래프: 레인·머지·워크트리 HEAD(detached 포함)·브랜치/원격/태그 배지 | E2E A + 단위 7개 + git log 대조 |
| ✅ | 포커스 HEAD 의 첫 부모 줄기 강조, 세션 시작 브랜치 ◷ 표시 | E2E F |
| ✅ | 커밋 상세(메시지·작성자·부모·파일), 파일 클릭 시 오른쪽에 커밋 diff | 화면 |
| ✅ | 변경 사항: 파일 선택 커밋(선택한 파일만 커밋, 이름 변경 포함) | E2E + 통합 테스트 |
| ✅ | Fetch(`--all --prune`), Pull(`--ff-only`, 확인창), Push(추적 없으면 `-u` 확인) | E2E (로컬 bare 원격) |
| ✅ | 체크아웃은 커밋 상세의 버튼 + 확인창으로만. 변경 있음/에이전트 실행 중이면 위험 표시, 다른 워크트리가 쓰는 브랜치는 미리 차단, `--force` 미사용 | E2E F + 통합 테스트 |
| ☑️ | merge/rebase/cherry-pick 진행 중 표시 | 코드 경로만 |

### 에이전트 (가운데)
| | 기능 | 검증 |
|---|---|---|
| ✅ | Claude Code 외부 세션 발견(cwd·시작/마지막 브랜치·제목) | E2E B + 실제 기록 54개 |
| ✅ | Codex 외부 세션 발견(state sqlite + `.jsonl.zst` rollout) | E2E C |

| ✅ | 기록 보기(사용자/에이전트/도구 실행, 최근 400개) | E2E B·C |
| ✅ | PTY 재개(`claude --resume`, `codex resume -C`), 이전 맥락 유지 | E2E B·C (암호 단어) |
| ✅ | 새 세션(Claude 는 `--session-id` 로 즉시 연결, Codex 는 시작 후 생긴 스레드와 연결) | 통합 테스트(가짜 CLI) |
| ✅ | 여러 세션 동시 실행, 전환해도 프로세스·화면 유지(2MB 출력 버퍼 재생) | E2E G |
| ✅ | 승인 요청·도구 출력: 원본 CLI 화면 그대로 | E2E (Codex 업데이트·신뢰 프롬프트) |
| ✅ | 에이전트가 작업한 파일(Claude Edit/Write, Codex apply_patch) + 지금 Git 상태. 셸 명령으로 고친 파일은 빠짐 | 화면 |
| ✅ | 대화 도중 다른 워크트리로 옮긴 세션은 지금 일하는 워크트리에 연결 | 통합 테스트 |
| ✅ | 세션 상태: 앱에서 실행 중 / 최근 기록됨(2분) / 최근 1시간 | 화면 |
| ✅ | 부모 에이전트 세션 환경변수(CLAUDECODE, CLAUDE_CODE_* 등) 차단 — 안 하면 재개한 Claude 가 기록 저장을 끔 | E2E 에서 발견·수정 |

## P1 — 2차 작업 (2026-10-21)

| | 기능 | 검증 |
|---|---|---|
| ✅ | **자체 채팅 UI — Claude**: `claude -p` stream-json 상주 프로세스, 기존 세션 이어가기·새 대화, 도구 승인 카드(실제 명령·경로·내용 표시, 허용/거부), 중단, 권한 모드(매번 묻기/편집 자동 허용/계획만) | 실제 CLI: 맥락 유지, 허용 → 파일 생성, 거부 → 미생성 |
| ✅ | **자체 채팅 UI — Codex**: 메시지마다 `codex exec --json` / `exec resume`, 샌드박스(읽기 전용/작업 폴더 쓰기), 새 대화는 첫 응답 뒤 스레드와 자동 연결 | 실제 CLI: 두 턴 맥락 유지, 세션 연결·선택 이동 |
| ✅ | 같은 대화를 터미널·채팅·외부에서 동시에 열지 않게 막기(외부는 경고 후 선택) | 실제 CLI + 단위 테스트 |
| ✅ | **외부 실행 감지**: Claude `~/.claude/sessions/<pid>.json` + 프로세스 시작 시각, Codex 대화 잠금 파일을 연 프로세스(libproc). 목록 태그·상세 배너·재개 경고 | 실제 tmux Claude, Codex Desktop |
| ✅ | **브랜치 체크아웃 방법**: 머리글 브랜치 전환 메뉴(검색), 브랜치 탭(더블클릭·⋯ 메뉴), 그래프 우클릭 메뉴, 커밋 상세 버튼. 다른 워크트리가 쓰는 브랜치는 "그 워크트리 보기"로 안내, 원격 브랜치는 추적 브랜치 생성 | E2E features 1 |
| ✅ | 새 브랜치(체크아웃 선택), 브랜치 삭제(병합된 것만) | E2E features 2 + 단위 |
| ✅ | **워크트리 생성·삭제**: 새 브랜치/기존 브랜치/커밋에서, 만든 뒤 화면 이동. 삭제는 변경 버림 동의·외부 에이전트 확인·메인 보호·병합된 브랜치 함께 삭제, 사라진 폴더는 정리(prune) | E2E features 3 + 단위 |
| ✅ | **hunk 단위 스테이징**: 스테이지 안 됨/됨 조각별 스테이지·취소·버리기, 화면과 실제가 다르면 거부(지문), UTF-8 아닌 파일·충돌 파일은 거부, 파일 단위 +/−/↺, 스테이지된 것만 커밋, 마지막 커밋 고치기 | E2E features 4 + 단위 |
| ✅ | **Merge/Rebase**: 비교 요약(앞/뒤 커밋 수), 방식 선택(ff/no-ff/ff-only), 이미 push 한 커밋 rebase 경고, 진행 배너(rebase 단계·대상), 충돌 파일별 현재 쪽/가져오는 쪽/해결됨, 계속·건너뛰기·중단, cherry-pick·revert·am·bisect 구분 | E2E features 5·6 + 단위 |
