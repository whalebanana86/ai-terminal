# 기능 목록

## P0 — MVP

### 레이아웃
| | 기능 | 검증 |
|---|---|---|
| ✅ | 3패널(기본 33/34/33%) 드래그 조절, 크기 기억(localStorage) | 화면 |
| ✅ | 상단 바: 저장소/워크트리 선택, 지금 보는 위치, CLI 설치 상태 | 화면 |
| ✅ | 재시작 시 저장소 목록·선택 세션·보던 워크트리 복원 | E2E H |

### Git (왼쪽)
| | 기능 | 검증 |
|---|---|---|
| ✅ | 로컬 저장소 추가(비공개 포함, git CLI 인증 그대로) | E2E A |
| ✅ | 워크트리 목록(경로·브랜치·HEAD·메인/링크·잠김·폴더 없음) | E2E A + 통합 테스트 |
| ✅ | 커밋 그래프: 레인·머지·워크트리 HEAD(detached 포함)·브랜치/원격/태그 배지 | E2E A + 단위 7개 + git log 대조 |
| ✅ | 포커스 HEAD 의 첫 부모 줄기 강조, 세션 시작 브랜치 ◷ 표시 | E2E F |
| ✅ | 커밋 상세(메시지·작성자·부모·파일), 파일 클릭 시 오른쪽에 커밋 diff | 화면 |
| ✅ | 변경 사항: 파일 선택 커밋(선택한 파일만 커밋, 이름 변경 포함) | E2E + 통합 테스트 |
| ✅ | Fetch(`--all --prune`), Pull(`--ff-only`, 확인창), Push(추적 없으면 `-u` 확인) | E2E (로컬 bare 원격) |
| ✅ | 체크아웃은 커밋 상세의 버튼 + 확인창으로만. 변경 있음/에이전트 실행 중이면 위험 표시, 다른 워크트리가 쓰는 브랜치는 미리 차단, `--force` 미사용 | E2E F + 통합 테스트 |
| ☑️ | merge/rebase/cherry-pick 진행 중 표시 | 코드 경로만 |

### 에이전트 (가운데)
| | 기능 | 검증 |
|---|---|---|
| ✅ | Claude Code 외부 세션 발견(cwd·시작/마지막 브랜치·제목) | E2E B + 실제 기록 54개 |
| ✅ | Codex 외부 세션 발견(state sqlite + `.jsonl.zst` rollout) | E2E C |
| ✅ | 세션 ↔ 저장소(common dir) ↔ 워크트리(toplevel) 연결, 하위 폴더 cwd 처리, 워크트리 삭제 후에도 저장된 연결 표시 | 통합 테스트 + E2E |
| ✅ | 기록 보기(사용자/에이전트/도구 실행, 최근 400개) | E2E B·C |
| ✅ | PTY 재개(`claude --resume`, `codex resume -C`), 이전 맥락 유지 | E2E B·C (암호 단어) |
| ✅ | 새 세션(Claude 는 `--session-id` 로 즉시 연결, Codex 는 시작 후 생긴 스레드와 연결) | 통합 테스트(가짜 CLI) |
| ✅ | 여러 세션 동시 실행, 전환해도 프로세스·화면 유지(2MB 출력 버퍼 재생) | E2E G |
| ✅ | 승인 요청·도구 출력: 원본 CLI 화면 그대로 | E2E (Codex 업데이트·신뢰 프롬프트) |
| ✅ | 에이전트가 작업한 파일(Claude Edit/Write, Codex apply_patch) + 지금 Git 상태. 셸 명령으로 고친 파일은 빠짐 | 화면 |
| ✅ | 대화 도중 다른 워크트리로 옮긴 세션은 지금 일하는 워크트리에 연결 | 통합 테스트 |
| ✅ | 세션 상태: 앱에서 실행 중 / 최근 기록됨(2분) / 최근 1시간 | 화면 |
| ✅ | 부모 에이전트 세션 환경변수(CLAUDECODE, CLAUDE_CODE_* 등) 차단 — 안 하면 재개한 Claude 가 기록 저장을 끔 | E2E 에서 발견·수정 |

### 파일 (오른쪽)
| | 기능 | 검증 |
|---|---|---|
| ✅ | 워크트리 실제 파일 트리(지연 로딩), `.gitignore` 무시 파일 숨김/보기 | E2E D |
| ✅ | 수정(M)·새 파일(U)·추가(A)·삭제(D, 디스크에 없어도 표시)·이름 변경·충돌, 폴더 변경 점 | E2E E |
| ✅ | 코드 미리보기(Shiki, 번들 내 문법, 1MB 까지), 바이너리 감지 | 화면 |
| ✅ | diff = `git diff HEAD` 출력 그대로(새 파일은 `--no-index`) | E2E E (CLI 와 줄 단위 일치) |
| ✅ | 에이전트·외부 에디터(원자적 저장 포함) 변경 자동 갱신 | E2E E |
| ✅ | 워크트리 밖을 가리키는 경로·심볼릭 링크·FIFO 거부, 등록되지 않은 워크트리 경로 거부 | 단위 테스트 + 앱 회귀 |
