## 코드행방 0.15.0 / Code Whereabouts 0.15.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **파일 트리 오른쪽 클릭 / Right-click in the file tree** — 파일·폴더·빈 곳을 오른쪽 클릭해 새 파일·새 폴더를 만들고, 이름을 바꾸고, 휴지통으로 옮겨요. 같은 이름이 있으면 덮어쓰지 않고, 이름을 바꾸면 열어 둔 탭과 저장하지 않은 수정이 새 이름을 따라가요. 지운 것은 Finder 의 휴지통에서 되살릴 수 있어요. / Right-click a file, a folder or empty space in the file tree to create a file or folder, rename, or move to the Trash. Existing names are never overwritten, and renaming carries open tabs and unsaved edits over to the new name. Anything deleted can be put back from the Trash in Finder.
- **탭 순서 바꾸기 / Reorder tabs** — 맨 위 저장소 탭과 가운데 칸의 열린 파일 탭을 끌어 원하는 자리에 놓아요. 저장소 탭 순서는 앱을 다시 켜도 그대로예요. 끄는 중에 Esc 를 누르면 그대로 둬요. / Drag the repository tabs at the top and the open file tabs in the middle pane to reorder them. The repository tab order is kept after you restart the app. Press Esc while dragging to leave everything as it was.
