## 코드행방 0.5.0 / Code Whereabouts 0.5.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **설정 → 기능 / Settings → Features** — 쓸 기능만 켭니다. 파일 편집은 처음에 꺼져 있고, 스틱맨과 구독 한도 표시는 켜져 있습니다. 꺼 둔 기능은 코드를 불러오지 않으며, 구독 한도 표시를 끄면 로그인 정보를 읽지 않습니다. / Turn on only what you use. File editing starts off; Stickman and subscription limits start on. Features that are off aren't loaded, and turning off subscription limits stops reading login details.
- **파일 편집 / File editing** — 켜 두면 파일을 열자마자 바로 고칠 수 있고, 파일은 가운데 칸의 탭으로 크게 열립니다(에이전트 탭의 터미널은 그대로). `⌘S` 저장, `⌘F` 찾기. 그사이 AI 나 다른 편집기가 파일을 바꿨으면 덮어쓰지 않고 묻습니다. 저장하지 않은 수정은 다른 파일에 다녀와도 남고, 탭을 닫을 때 저장하고 닫기·저장하지 않고 닫기·취소를 고릅니다. 탭 오른쪽 클릭으로 닫기·다른 탭 모두 닫기·모두 닫기. 줄바꿈(CRLF)·BOM·파일 권한을 지킵니다. 켤 때 맥 확인창이 뜨고, 꺼져 있으면 앱은 파일을 저장하지 않습니다. / When on, files are editable as soon as you open them and open as large tabs in the center pane (agent terminals keep running). `⌘S` save, `⌘F` find. If an AI or another editor changed the file meanwhile, it asks instead of overwriting. Unsaved edits survive switching files; closing asks Save and close / Close without saving / Cancel. Right-click a tab for Close / Close other tabs / Close all. Line endings, BOM and permissions are kept. Turning it on asks for macOS confirmation; while off, the app never writes your files.
- **내 수정 워크트리 / Edit in my own worktree** — AI 가 일하는 워크트리에서 고치려 하면 알려 주고, 옆 폴더에 `edit/<AI 브랜치>` 워크트리를 열어 따로 고친 뒤 커밋해서 AI 브랜치에 합칠 수 있습니다. / When an AI is working in that worktree, you can edit in a sibling `edit/<AI branch>` worktree instead, commit, and merge into the AI branch.
- **외부 편집기로 열기 / Open in external editor** — 파일 보기의 ↗ 로 VS Code·Cursor·Zed 등 설치된 편집기로 엽니다(설정에서 고름). / ↗ in the file viewer opens the file in an installed editor (VS Code, Cursor, Zed…), chosen in Settings.
- **Git 시작 제안 / Start Git** — Git 저장소가 아닌 폴더를 추가하면 `git init` 을 제안합니다(홈·시스템 폴더 제외). / Adding a folder that isn't a Git repository offers `git init` (not in home or system folders).
- **고친 것 / Fixed** — `pnpm install` 이 켜져 있는 코드행방을 알아채지 못하던 문제. / `pnpm install` now notices a running Code Whereabouts.
