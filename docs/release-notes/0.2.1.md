## AI Terminal 0.2.1

- **설정은 메뉴 막대에 / Settings in the menu bar** — 언어·화면 모드는 이제 맥 메뉴 막대 **AI Terminal → 설정… (⌘,)** 에서 열어요(상태줄 버튼은 없앰). / Language and appearance moved to **AI Terminal → Settings… (⌘,)**.
- **파일 끌어다 놓기 고침 / Drag and drop fixed** — 맥에서 파일을 터미널·입력칸에 놓아도 경로가 안 들어가던 문제를 고쳤어요(놓은 위치를 잘못 계산하고 있었음). / Dropping files onto the terminal or a text field now inserts their paths on macOS.
- **터미널 한글 입력 표시 / Korean input display** — 조합 중인 글자가 바로 앞 글자를 덮어 "푸시해"가 "푸해"처럼 보이던 문제를 고쳤어요(입력된 글자는 원래 맞았음). / The composing preview no longer covers the previous character.
