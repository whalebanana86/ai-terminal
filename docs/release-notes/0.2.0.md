## AI Terminal 0.2.0

- **언어 설정 / Language** — 아래 상태줄 ⚙ 설정에서 한국어·English 를 골라요. 화면 글자와 앱이 내보내는 오류까지 바뀌어요(처음엔 맥 언어를 따라감). / Korean or English UI, including backend messages; follows macOS at first.
- **화면 모드 / Appearance** — 시스템·밝게·어둡게. 새 밝은 화면을 넣었고 터미널·코드 강조 색도 따라가요. / New light theme; system / light / dark, terminal and code colours follow.
- **스틱맨 / Stick figure** — 위쪽 막대에서 AI 에게 보낸 요청을 추가·수정·삭제·버그·질문으로 나눠 동작하고 오늘 개수를 세요. 평소에는 서성이고(CPU 거의 안 씀), 목록에서 줄을 누르면 그 동작을 다시 보여 줘요. / Acts out each new request and counts them; click a row to replay.
- **대기열 요청도 셈 / Queued prompts counted** — Claude 가 일하는 중에 보낸 요청도 스틱맨 개수와 대화 탭에 나와요. 오래 일한 긴 세션에서도 최근 요청을 찾아요. / Prompts sent while Claude is working are now counted and shown.
- **파일 끌어다 놓기 / Drag files in** — 터미널(Claude Code 입력줄)에 놓으면 경로를 붙여넣어 그림으로 인식되고, 입력칸에 놓으면 경로가 들어가요. / Drop files onto the terminal or a text field to insert their paths.
- **코드로 설치 / From source** — `pnpm install` 하면 앱을 만들어 응용 프로그램 폴더에 넣어요(`pnpm install-app`, 건너뛰려면 `AITERM_SKIP_APP=1`). / `pnpm install` now builds and installs the app.
