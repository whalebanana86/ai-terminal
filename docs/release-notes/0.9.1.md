## 코드행방 0.9.1 / Code Whereabouts 0.9.1

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **쉬는 동안 CPU 를 거의 쓰지 않아요 / Near-zero CPU while idle** — 아무것도 하지 않을 때도 화면을 계속 다시 그려 CPU 를 몇 % 쓰던 것을 고쳤습니다. 터미널 커서는 깜빡이지 않고, 스틱맨은 앱을 쓰는 중(창이 활성이고 30초 안에 마우스·키보드를 씀)일 때만 서성입니다. 새 요청이 오면 하는 동작은 그대로입니다. / The app no longer redraws the screen while idle, which used a few percent of CPU. The terminal cursor no longer blinks, and the stick figure only wanders while you're using the app (window active and touched within 30 seconds); its reactions to new requests are unchanged.
- **이번 업데이트부터 에이전트가 끊기지 않아요 / Agents keep running through this update** — 0.9.0 에서 설치하면 터미널에서 실행 중인 에이전트가 새 버전으로 그대로 넘어갑니다. / Updating from 0.9.0 hands agents running in a terminal over to the new version.
