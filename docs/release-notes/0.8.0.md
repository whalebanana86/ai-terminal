## 코드행방 0.8.0 / Code Whereabouts 0.8.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **터미널에서 파일 열기 / Open files from the terminal** — 터미널 출력에 나온 저장소 안의 파일 경로를 클릭하면 앱에서 파일을 엽니다. 파일 편집 기능이 켜져 있으면 가운데 파일 탭에서, 꺼져 있으면 파일 미리보기에서 표시합니다. / Click file paths in terminal output to open them inside the app, in a center file tab when File editing is enabled or in the file preview otherwise.
- **여러 경로 형식 지원 / Path formats** — 상대·절대 경로, `파일.ts:줄:열`과 `#L줄` 표기, 따옴표로 감싼 공백·한글 경로를 인식합니다. 한글 뒤의 링크 위치와 여러 터미널 행에 걸쳐 줄바꿈된 긴 경로도 처리합니다. 줄·열 표기는 파일 경로 인식에 사용하며, 해당 위치로 자동 이동하지는 않습니다. / Recognizes relative and absolute paths, `file.ts:line:column` and `#Lline` suffixes, quoted paths with spaces or Korean characters, and paths wrapped across terminal rows. Line and column suffixes identify the file; they do not navigate to a particular position.
- **저장소 범위 확인 / Worktree boundaries** — 해당 터미널의 저장소와 실행 폴더를 기준으로 실제 존재하는 파일만 연결합니다. 없는 파일·폴더·저장소 밖 경로와 바깥을 가리키는 심볼릭 링크는 제외하고, 클릭할 때 파일을 다시 확인합니다. / Links resolve against the terminal's worktree and launch directory. Only existing files inside that worktree are linked; missing files, directories, external paths and escaping symlinks are excluded, and each click rechecks the file.
