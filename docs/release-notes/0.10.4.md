## 코드행방 0.10.4 / Code Whereabouts 0.10.4

- **빌드 정리 / Build cleanup** — 맥 앱에 쓰지 않는 iOS·Android용 라이브러리를 더는 만들지 않습니다. 소스에서 직접 빌드할 때 빌드마다 수백 MB씩 생기던 파일이 없어지고 빌드가 조금 빨라집니다. 앱 사용에는 바뀌는 것이 없습니다. / The iOS and Android libraries, unused by the Mac app, are no longer built. Building from source no longer leaves a file of several hundred MB on every build and is a little faster. Nothing changes when using the app.
