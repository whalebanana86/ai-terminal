## 코드행방 0.11.0 / Code Whereabouts 0.11.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **기억 담아 새로 / Start fresh with memory** — 세션 위쪽 **기억 담아 새로** 버튼으로, 지난 대화 전체를 다시 보내는 대신 **최근 대화 몇 턴 + 고른 지난 기록**만 담아 새 세션을 열어요. 길어진 대화를 이어갈 때 토큰을 아끼고 오래된 맥락이 섞이지 않아요. 넣을 글은 미리 보고 고를 수 있어요(Claude 는 시작할 때 컨텍스트로, Codex 는 첫 메시지로 들어가요). / The new **Fresh with memory** button opens a new session with only the last few turns plus past records you pick, instead of sending the whole long conversation again. It saves tokens and keeps stale context out; you can preview and choose what goes in (Claude gets it as start-up context, Codex as the first message).
- **작업 기억 / Work memory** — 설정 → 작업 기억을 켜면 지난 대화·오류·수정 내역을 이 맥 안에 보관하고(Claude Code 는 30일 지난 대화를 지워요) 뜻으로 찾아서, 위 창에 관련 기록을 띄워 줘요. 처음엔 꺼져 있고, 켤 때 검색 모델(약 380MB)을 한 번 내려받아요. 비밀번호·키처럼 보이는 값은 저장 전에 가리고, 기록은 밖으로 보내지 않아요. Apple Silicon + macOS 14 이상에서 쓸 수 있어요. / Settings → Work memory keeps past conversations, errors and edits on this Mac (Claude Code deletes conversations after 30 days) and finds related ones by meaning for the dialog above. Off by default; turning it on downloads a search model (about 380 MB) once. Values that look like passwords or keys are masked before saving, and nothing leaves your Mac. Available on Apple Silicon with macOS 14 or later.
- **오픈소스 라이선스 / Open source licenses** — 설정 맨 아래에서 함께 쓰는 오픈소스의 라이선스와 원문을 볼 수 있어요. 코드행방은 그대로 MIT 라이선스예요. / Settings now lists the licenses and full texts of the open source software the app uses. Code Whereabouts stays under the MIT License.
