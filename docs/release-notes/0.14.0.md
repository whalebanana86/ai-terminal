## 코드행방 0.14.0 / Code Whereabouts 0.14.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **md 미리보기 / Markdown preview** — md 파일을 누르면 제목·표·목록·체크 칸·코드 색·저장소 안 그림을 갖춘 문서로 먼저 보여 줘요(원문은 **내용** 탭). 미리보기 안 링크는 앱이 처리해요: `#제목` 은 그 자리로, 저장소 안 파일은 파일 보기로, 바깥 주소는 브라우저로. 저장소 문서는 남이 쓴 것일 수 있어 스크립트 같은 위험한 내용은 걸러 내요. / Markdown files now open as a formatted document first, with headings, tables, lists, checkboxes, coloured code and images from the repo (the source is under **Content**). Links in the preview are handled by the app: `#heading` scrolls there, repo files open in the viewer, and web addresses open in your browser. Risky content such as scripts is stripped, since repo documents may come from anyone.
- **브라우저로 열기 / Open in browser** — md 머리의 🌐 버튼으로 꼴 갖춘 문서를 브라우저에서 열어요. md 를 크롬에 그냥 끌어다 놓으면 한국어 설정의 크롬이 한글을 깨뜨리는데(옛 한국어 인코딩으로 짐작), 이 버튼은 UTF-8 웹 문서로 바꿔 열어서 안 깨져요. 쓸 브라우저는 설정 → **브라우저**에서 골라요(처음엔 맥 기본 브라우저). / The 🌐 button in the Markdown header opens the formatted document in a browser. Dropping a raw .md onto Chrome set to Korean garbles the text (Chrome guesses a legacy encoding); this button converts it to a UTF-8 page first, so it reads correctly. Choose the browser under Settings → **Browser** (the Mac default at first).
- **긴 줄 접기 / Long lines wrap** — 파일 보기(내용·변경·일부 담기·파일 편집)의 긴 줄을 칸 너비에서 접어 좌우 스크롤이 생기지 않아요. 들여쓰기는 그대로예요. / Long lines in the file viewer (content, diff, stage and the editor) wrap at the pane width, so there's no sideways scrolling. Indentation is kept.
