## 코드행방 0.6.0 / Code Whereabouts 0.6.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **AI 가 같이 쓴 커밋 표시 / AI co-authored commits** — 그래프의 커밋 줄에 🤖 가 붙으면 AI 와 함께 쓴 커밋입니다(커밋 메시지의 `Co-authored-by` 가 Claude·Codex·Copilot·Cursor·Gemini). 커밋을 누르면 작성자 이메일, 함께 쓴 AI·사람, 작성자와 다르면 커밋한 사람도 보여 줍니다. / A 🤖 on a graph row marks a commit co-written by an AI (a `Co-authored-by` trailer from Claude, Codex, Copilot, Cursor or Gemini). Commit details show the author's email, co-authors (AI or people) and the committer when different.
- **작성자 칸 정리 / Tidier author column** — 혼자 쓰는 저장소에서는 작성자 칸을 빼서 커밋 제목을 넓게 보여 주고, 여럿이면 이름 대신 회색 머리글자 동그라미(마우스를 올리면 이름·이메일)로 보여 줍니다. / Single-author repositories drop the author column so subjects get the space; with several authors an initials circle replaces the name (hover for name and email).
- **.mailmap 지원 / .mailmap support** — 그래프와 커밋 상세의 이름·이메일이 저장소의 `.mailmap` 을 따릅니다. 여러 이름으로 커밋한 같은 사람을 하나로 묶을 수 있습니다. / Names and emails in the graph and commit details follow the repository's `.mailmap`, so one person who committed under several names shows as one.
