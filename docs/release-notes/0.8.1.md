## 코드행방 0.8.1 / Code Whereabouts 0.8.1

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **터미널 입력칸이 사라지던 문제 / Missing input box after switching repositories** — 세션을 고르지 않은 저장소에 갔다 오면 터미널을 새로 만들며 잘린 출력 기록을 재생해, 에이전트의 입력칸이 안 보이거나 화면이 어긋날 때가 있었습니다. 이제 저장소·세션을 오가도 터미널을 그대로 두고, 다시 붙은 터미널은 에이전트가 화면 전체를 다시 그립니다. / Visiting a repository with no session selected used to rebuild the terminal from a truncated output replay, which could hide the agent's input box or misalign the screen. Terminals now stay alive while you switch repositories or sessions, and a reattached terminal has the agent redraw the whole screen.
- **화면이 왼쪽으로 쏠리던 문제 / Screen squeezed to 80×24** — 칸 크기를 재기 전의 기본 크기(80×24)를 에이전트에 알려, 에이전트가 좁고 짧게 그리고 글자가 겹쳐 보일 때가 있었습니다. 이제 크기를 잰 뒤에만 알리고, WebGL 이 끊겨 그리기 방식이 바뀌어도 크기를 다시 재고 다시 그립니다. / The terminal could report its unmeasured default size (80×24), so the agent drew a narrow, short screen with overlapping text. The size is now reported only after it is measured, and the terminal re-measures and redraws when its WebGL context is lost.
