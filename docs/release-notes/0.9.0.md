## 코드행방 0.9.0 / Code Whereabouts 0.9.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **업데이트해도 에이전트가 끊기지 않아요 / Updates no longer stop your agents** — 다음 업데이트부터는 터미널에서 실행 중인 에이전트를 끝내지 않고 새 버전으로 넘깁니다. 일하던 중이어도 그대로 이어지고 화면 기록도 남습니다(채팅 화면에서 응답 중이면 끝날 때까지 기다립니다). 이 기능은 0.9.0 에 들어 있으므로, 0.9.0 으로 올리는 이번 한 번은 에이전트를 끝낸 뒤 설치해 주세요. / From the next update on, agents running in a terminal are handed to the new version instead of being stopped — even mid-task, with their screen history kept (an agent answering in a chat is waited for). Since this arrives in 0.9.0, stop your agents once before installing this update.
- **파일 트리 끌어다 놓기 / Drag and drop in the file tree** — 트리의 파일을 터미널·입력칸에 끌어 놓으면 경로가 들어가고(작업 폴더 안이면 상대 경로), 다른 폴더에 놓으면 옮겨지고, Finder·다른 앱에 놓으면 파일이 넘어갑니다. Finder 에서 트리 폴더에 끌어 놓으면 복사합니다(같은 이름이면 "이름 2"). / Drag a file from the tree into a terminal or text box to insert its path (relative inside the agent's folder), onto another folder to move it, or out to Finder and other apps to hand over the file. Dropping files from Finder onto a tree folder copies them in ("name 2" on a clash).
- **어두운 화면에서 검은 글자 / Black text on the dark screen** — Claude 를 밝은 테마로 설정해 두면 질문 제목 같은 글자가 검게 나와 어두운 터미널 바탕에 묻혔습니다. 앱이 띄우는 Claude 는 이제 앱 화면 모드에 맞는 테마로 실행합니다(설정 파일은 그대로). / With Claude set to a light theme, some text such as question titles came out black on the dark terminal. Claude started from the app now uses a theme matching the app's appearance (your settings file is untouched).
- **저장소마다 따로 보이는 파일 탭 / File tabs per repository** — 다른 저장소에서 연 파일 탭이 따라오지 않고, 돌아오면 마지막으로 보던 탭이 다시 보입니다. / File tabs opened in another repository no longer follow you; coming back shows the tab you last viewed there.
- **그래프의 브랜치 색 / Branch colors in the graph** — 브랜치 이름표를 그 커밋을 지나는 선의 색으로 칠합니다. / Branch labels now take the color of the graph line they sit on.
- **그 밖 / Also** — "Finder 에서 보기"·"외부 편집기로 열기" 가 끝난 프로세스를 남기던 문제를 고쳤습니다. / Fixed leftover finished processes from Reveal in Finder and Open in external editor.
