## 코드행방 0.4.0 / Code Whereabouts 0.4.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **저장소 탭 관리 / Repository tab management** — ＋로 탭을 열고 × 또는 Delete로 닫을 수 있습니다. 열린 탭과 마지막 워크트리를 기억하며, 자동 발견한 저장소가 탭으로 열리지 않습니다. 탭을 닫아도 저장소 파일이나 실행 중인 에이전트는 유지됩니다. / Open tabs with ＋ and close them with × or Delete. Open tabs and their last worktrees persist across restarts. Discovered repositories no longer open automatically, and closing a tab preserves files and running agents.
- **세션 복원 / Session restoration** — 다른 저장소를 봤다가 돌아오면 마지막으로 선택한 에이전트 세션을 다시 보여 줍니다. 이전 선택이 없으면 해당 워크트리의 실행 중인 세션을 우선 선택합니다. / Returning to a repository restores its selected agent session, or selects a running session in the worktree when no previous selection is available.
- **구독 한도 사용률 / Subscription quota usage** — 하단에 Claude·Codex의 5시간·주간 한도 사용률을 표시합니다. 마우스를 올리면 초기화·조회 시각을 확인할 수 있습니다. 창이 보일 때 2분마다 조회하며, 로그인 정보가 없거나 조회에 실패하면 확인 불가로 표시합니다. / The footer shows Claude and Codex subscription quota usage for five-hour and weekly windows. Hover for reset and check times. Usage refreshes every two minutes while visible; missing authentication or failed queries show as unavailable.
- **요청 분류와 아이콘 / Request classification and icon** — 의도를 분류하기 어려운 요청은 추가로 집계합니다. 명확한 질문은 질문으로 유지하며, 추가 아이콘을 Sparkles로 바꿨습니다. / Unrecognized requests count as additions, explicit questions remain questions, and additions now use the Sparkles icon.

구독 한도 조회는 기존 CLI 로그인으로 제공자의 사용량 메타데이터만 요청하며, AI 추론 요청을 실행하지 않습니다. 대화 내용이나 저장소 경로를 전송하지 않습니다. Claude의 조회는 유효한 OAuth 로그인과 사용량 endpoint 제공 여부에 따라 사용할 수 있습니다. / Quota checks request provider usage metadata using existing CLI authentication without running inference or sending conversation contents or repository paths. Claude usage availability depends on valid OAuth authentication and its usage endpoint.
