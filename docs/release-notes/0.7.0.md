## 코드행방 0.7.0 / Code Whereabouts 0.7.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **세션 목록 접기 / Hide the session list** — 에이전트 칸 머리줄의 목록 접기 버튼(또는 경계를 위로 끝까지 끌기)으로 세션 목록을 접으면 터미널·채팅이 칸 전체 높이를 씁니다. 접은 상태와 높이는 기억합니다. / The hide-list button in the Agents header (or dragging the divider all the way up) folds the session list away so the terminal or chat gets the whole pane height. The state and heights are remembered.
- **한글이 벌어지지 않는 터미널 글꼴 / Terminal font with proper Hangul width** — 터미널 글꼴을 한글이 영문 정확히 두 칸 폭인 Haengbang Mono(D2Coding 수정본, SIL OFL 1.1)로 바꿨습니다. 한글 사이가 벌어지지 않고, 글자는 조금 커졌는데 한 줄에 약 15% 더 들어갑니다. / The terminal now uses Haengbang Mono (a modified D2Coding, SIL OFL 1.1) whose Hangul is exactly two Latin cells wide: no gaps between Korean characters, slightly larger text, and about 15% more per line.
