## 코드행방 0.17.0 / Code Whereabouts 0.17.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **저장소 탭을 닫을 때 AI 를 멈출지 물어요 / Asks whether to stop the AI when you close a repository tab** — 앱 터미널에서 띄운 AI 가 그 저장소에서 아직 돌고 있으면, 탭을 닫기 전에 몇 개가 어떤 상태인지 보여 주고 물어요. "멈추고 닫기"는 AI 를 끝내고 닫고, "그대로 두고 닫기"는 탭만 닫아요. 대화 기록은 남아 나중에 이어갈 수 있어요. 다른 터미널에서 띄운 AI 는 끝내지 않아요. / If an AI started in the app's terminal is still running in that repository, closing its tab first shows how many are running and in what state, and asks. "Stop and close" ends the AI and closes the tab; "Close and leave running" closes only the tab. The conversation is kept, so you can continue it later. AI started in another terminal is never stopped.
