## AI Terminal 0.1.0 — 첫 공개 / First release

내 맥의 Claude Code·Codex 세션이 **어느 저장소·워크트리·브랜치에서** 일하는지 보면서 대화를 이어 가고, Git 과 파일까지 한 화면에서 보는 맥 앱이에요.
See which repository, worktree and branch each of your Claude Code / Codex sessions works in, continue any of them, and keep Git and files on the same screen.

- **세 칸 화면** — Git 그래프(워크트리마다 색, 지하철 노선도) · 에이전트 세션(오늘·어제·이번 주) · 파일. 세션을 고르면 Git·파일이 그 워크트리로 따라가요(체크아웃 없이). / Three panes that follow the selected session's worktree, without checking anything out.
- **이어가기** — 원본 CLI 터미널(`claude --resume`, `codex resume`) 또는 앱 채팅 화면(도구 허락 카드). 새 세션·첫 지시·새 워크트리에서 시작. / Continue in the original CLI or in a chat view with permission cards.
- **Git** — 브랜치 전환·만들기·지우기, 워크트리 만들기·지우기, 부분(hunk) 담기, 담은 것만 커밋, 병합·리베이스와 충돌 해결, 원격 확인·받기(ff-only)·올리기.
- **파일** — 종류별 아이콘, 바뀐 표시, 코드 미리보기·diff, 그림 보기(마지막 커밋과 나란히), 파일을 터미널·입력칸에 끌어다 놓으면 경로. / File icons, diffs, image preview and compare, drag a file in to paste its path.
- **스틱맨** — AI 에게 보낸 요청을 추가·수정·삭제·버그·질문으로 나눠 동작하고 오늘 개수를 세요. / A stick figure that acts out each new request and counts them.
- **터미널 한글 입력** 수정, 외부에서 실행 중인 세션 표시, 상위 폴더에서 시작한 세션도 그 저장소에 연결.
- 로컬 전용(가입 없음, 앱은 네트워크로 보내지 않음), 가벼움(CPU 0.7%·메모리 150MB 안팎). / Local only, lightweight.

화면 글자는 아직 한국어만 지원해요. / The UI is in Korean for now.
