## 코드행방 0.10.2 / Code Whereabouts 0.10.2

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **저장소 믿기 / Trust a repository** — 새로 추가한 저장소의 Git 설정(.git)에 실행되는 명령(변환 필터·훅 등)이 있으면, 믿는다고 하기 전에는 꺼 둔 채로 열고 확인 창으로 물어요. 남에게 받은 저장소를 열기만 해도 명령이 실행되던 문제를 막습니다. 이미 쓰던 저장소는 그대로입니다. / If a newly added repository's Git settings contain commands Git would run (filters, hooks, …), they stay off until you trust it. Opening a repository from someone else no longer runs them. Repositories you already use are unaffected.
- **업데이트 확인이 막히지 않아요 / Update checks keep working** — GitHub 요청 한도(로그인 없이 시간당 60번)에 걸려도 최신 업데이트 파일로 바로 확인합니다. / When GitHub's request limit (60 per hour without signing in) is reached, the app checks the latest update file directly instead.
- **업데이트 때 에이전트 넘기기가 더 단단해요 / Sturdier agent handoff during updates** — 넘기는 순간 끝난 에이전트가 '실행 중'으로 남지 않고, 넘겨받지 못하면 알려 줍니다. 넘기는 연결은 코드행방 앱만 받습니다. / Agents that finish mid-handoff no longer stay "running", failures are reported, and only Code Whereabouts itself can take over the agents.
- **작은 고침 / Fixes** — 새 터미널에 바로 입력, 다른 저장소 탭으로 넘어가 빈 화면 되던 문제, 이름에 줄바꿈이 든 파일을 끌어 놓을 때 경로 넣지 않기, `.git` 안 파일을 링크로 고치지 못하게, 그래프 색 기록이 쌓여 화면이 하얗게 될 수 있던 문제, 스틱맨이 쉬지 않고 걷던 문제. / New terminals take typing right away; closing a tab no longer jumps to another repository's hidden tab; dropped file names with line breaks are not inserted; `.git` can't be edited through links; graph color history can no longer blank the window; the stick figure rests again.
