## 코드행방 0.10.1 / Code Whereabouts 0.10.1

- **간결한 Codex 터미널 / Simpler Codex terminal** — 요청마다 모델을 자동 선택하는 터미널을 제거하고 원본 Codex CLI로 통일했습니다. 앱 채팅 화면도 제거해 새 세션과 이어가기는 원본 CLI 터미널을 엽니다. / Removed the automatic model-routing terminal and app chat view. New and resumed sessions use the original Codex CLI terminal.
- **그래프 선 두께 / Graph line weight** — 메인 브랜치는 3px로 유지하고 다른 갈래는 2px로 표시합니다. 좁은 Git 패널에서는 브랜치 전환 버튼이 안내 아래로 이동합니다. / Keeps the main branch at 3px and draws other branches at 2px. The branch switch button moves below the notice in narrow Git panels.
