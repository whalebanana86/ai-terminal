## 코드행방 0.13.0 / Code Whereabouts 0.13.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **PDF 보기 / PDF viewer** — 파일 패널에서 PDF 를 누르면 앱 안에서 바로 열려요. 맥 기본 PDF 보기라 쪽 넘김·확대·글 고르기가 그대로 되고 한글도 잘 보여요. 바뀐 PDF 는 그림처럼 마지막 커밋과 지금을 나란히 놓고, 그래프에서 커밋의 PDF 를 열어도 PDF 로 보여요. 머리의 **↗** 는 PDF 를 미리보기 같은 기본 앱으로 열어요(안전을 위해 기본 앱으로는 PDF 만 열어요). / Click a PDF in the Files pane and it opens right in the app, using the built-in macOS PDF view, so paging, zoom and text selection work as usual. A changed PDF is shown next to its last committed version, just like images, and PDFs from a commit in the graph open as PDFs too. **↗** in the header opens the PDF in your default app such as Preview (for safety, only PDFs open in the default app).
