## 코드행방 0.10.0 / Code Whereabouts 0.10.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **Codex 모델 자동 선택 / Automatic Codex model selection** — 단순 작업은 GPT-6 Luna Low, 일반 개발은 GPT-6.1 Sol Low, 복잡한 개발은 GPT-6.1 Sol Medium으로 실행합니다. 앱 안에서 요청 문구를 분류하며 추가 분류 API를 호출하지 않습니다. / Uses GPT-6 Luna Low for simple tasks, GPT-6.1 Sol Low for general development, and GPT-6.1 Sol Medium for complex development, with local classification and no additional classification API calls.
- **전송 전 확인과 직접 선택 / Preview and manual selection** — 모델을 직접 고르거나 CLI 설정을 유지할 수 있습니다. 앱 채팅은 메시지마다 선택하고 짧은 이어가기 요청은 직전 분류를 유지합니다. 원본 터미널은 첫 지시의 시작 모델만 선택하며 이후에는 CLI의 `/model`로 변경합니다. / Preview or override the selection, or keep CLI settings. App chat selects per message and keeps the previous category for short continuations. The original terminal selects only its starting model; use `/model` for subsequent changes.
- **저장소 전환 시 터미널 표시 안정화 / Stable terminal rendering when switching repositories** — 크기와 글꼴이 준비된 뒤 터미널을 표시해 전환 중 글자가 잠깐 깨지는 현상을 줄였습니다. / Shows the terminal after its size and fonts are ready to prevent transient garbled text during switches.
- **병합 후에도 그래프 색상 유지 / Preserve graph colors after merging** — 작업 트리를 제거해도 갈래 색상을 유지하고 병합 커밋에 표시를 추가했습니다. / Keeps history colors after a worktree is removed and marks merge commits.
