## 코드행방 0.3.0 / Code Whereabouts 0.3.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **새 이름 / New name** — AI Terminal이 코드행방으로 바뀝니다. 영어 화면에서는 Code Whereabouts로 표시하며, 이름·부제·창 제목·앱 메뉴·정보 창을 함께 번역합니다. 기존 저장소와 세션 설정은 유지됩니다. / AI Terminal is now Code Whereabouts, with localized Korean and English branding throughout the app. Existing repositories and session settings are preserved.
- **저장소 탭 / Repository tabs** — 저장소를 추가하면 탭이 생깁니다. 탭을 전환하면 Git·AI 세션·파일이 함께 바뀌고 저장소별 마지막 워크트리를 기억합니다. / Added repositories appear as tabs. Switch Git, agent sessions and files together, with the last worktree remembered for each repository.
- **앱 메뉴에서 업데이트 / Updates from the app menu** — 메뉴에서 최신 정식 버전을 확인하고 서명된 업데이트를 다운로드·검증·설치할 수 있습니다. 설치 후 앱이 재시작되며, 실행 중인 에이전트나 응답 중인 채팅이 있으면 설치를 멈춥니다. / Check for stable releases, download and verify signed updates, then install and restart. Updates are blocked while terminal agents or chat responses are running.
- **창 이동 수정 / Window dragging fixed** — 상단 이름이나 빈 영역을 끌어서 창을 이동할 수 있도록 누락된 권한을 추가했습니다. / Restored the permission required to move the window by dragging the title area.
- **설치 개선 / Installation improvements** — 로컬 앱 번들의 임시 서명을 검증하고, 기존 AI Terminal.app을 코드행방.app으로 옮깁니다. 실행 중인 에이전트를 강제로 종료하지 않습니다. / Local installations verify the app's ad-hoc signature and migrate the old app name without forcibly stopping agents.

업데이트 확인은 사용자가 메뉴를 누를 때만 GitHub에 접속합니다. 대화 내용과 저장소 경로는 전송하지 않습니다. 업데이트 서명은 Apple Developer ID 서명·공증과 별개입니다. / Update checks contact GitHub only when requested. Conversation contents and repository paths are not sent. Update signatures are separate from Apple Developer ID signing and notarization.
