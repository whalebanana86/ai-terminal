## 코드행방 0.17.1 / Code Whereabouts 0.17.1

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **Git 상태 읽기를 줄였어요 / Fewer Git status reads** — 파일이 바뀌면 Git 패널, 파일 트리, 에이전트의 바꾼 파일이 각자 `git status` 를 돌리던 것을 한 번으로 합쳤어요. 파일 하나가 바뀔 때 3번에서 1번으로, 스테이지할 때 9번에서 2번으로 줄었어요. 화면에 보이는 내용은 그대로예요. / When files change, the Git panel, the file tree and the agent's changed-files view used to run `git status` separately; they now share one run. A single file change goes from 3 runs to 1, and staging from 9 to 2. What you see stays the same.
