## 코드행방 0.16.0 / Code Whereabouts 0.16.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **저장소 탭에 AI 표시 / AI status on repository tabs** — 맨 위 저장소 탭의 이름 뒤에 그 저장소에서 지금 AI 가 쓰이는지 점으로 보여요. 주황 마름모는 승인이나 질문의 답을 기다리는 중, 초록 점은 일하는 중, 초록 테두리는 Codex 처럼 일하는지 알 수 없는 에이전트가 켜져 있음, 회색 테두리는 할 일을 끝내고 기다리는 중이에요. 여럿이면 가장 급한 것 하나만 보이고, 마우스를 올리면 상태별 개수가 나와요. 앱 터미널과 다른 터미널에서 띄운 것을 함께 세고, 워크트리와 하위 폴더도 그 저장소로 쳐요. 표시는 몇 초 늦게 바뀔 수 있어요. / A mark after each repository tab's name shows whether AI is in use there right now. An orange diamond means it is waiting for an approval or an answer, a green dot means it is working, a green ring means an agent that doesn't report whether it's working (such as Codex) is running, and a grey ring means it finished and is waiting. With several agents, only the most urgent one is shown; hover to see the count for each state. Agents started in the app's terminals and in other terminals are both counted, and worktrees and subfolders count toward their repository. The mark may take a few seconds to update.
