## 코드행방 0.9.2 / Code Whereabouts 0.9.2

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **세션이 많아도 메모리를 덜 써요 / Less memory with many sessions** — 화면에 보이는 터미널만 그래픽 가속(WebGL)으로 그리고, 숨은 터미널은 그래픽 영역을 반납합니다. 숨은 터미널 하나에 약 10MB 줄어듭니다(WebKit 이 정리하는 때에 풀려 조금 늦을 수 있음). / Only the visible terminal is drawn with GPU acceleration (WebGL); hidden terminals give their graphics memory back — about 10 MB each, freed when WebKit next cleans up.
- **세션이 많을 때 터미널이 깨지지 않아요 / No broken terminals with many sessions** — 그래픽 가속을 동시에 쓸 수 있는 개수(약 16개)를 넘으면 오래된 터미널이 끊겨 화면이 어긋날 수 있었는데, 이제 늘 하나만 써서 그런 일이 없습니다. / Previously, going past the browser's limit of about 16 GPU contexts could cut off older terminals and garble them; now only one is used at a time.
