## 코드행방 0.12.0 / Code Whereabouts 0.12.0

**AI가 어디서 무엇을 바꾸는지 / See where AI works and what it changes**

- **캐릭터 부기 / Meet Buki** — 가지(브랜치)에 앉은 보라색 픽셀 부엉이 **부기**가 위쪽 막대 오른쪽의 스틱맨 자리를 이어받았어요. AI 에게 요청이 가면 종류마다 짧게 움직이고(추가: 깡충 + 초록 +, 수정: 렌치로 콕콕, 삭제: 상자 떨어뜨리기, 버그: 벌레 잡기, 질문: ?) 오늘 요청 수를 세요. 앉은 가지 색은 지금 보는 워크트리 색이에요. 평소엔 쓰는 중일 때만 가끔 깜빡이거나 두리번거려요. 세션 고르기 빈 화면, 설정 → 작업 기억(꺼져 있으면 졸아요), 기억 담아 새로 창, 업데이트 창에도 나와요. 설정 → 기능의 **부기**로 끌 수 있고, 스틱맨 때 켜고 끈 설정과 오늘 개수는 그대로 이어져요. / **Buki**, a purple pixel owl sitting on a branch, takes over the stick figure's spot at the right of the top bar. It acts out each kind of request (add: hop with a green +, modify: tap with a wrench, delete: drop a box, bug: catch a bug, question: ?) and counts today's requests. The branch it sits on takes the color of the worktree you're viewing, and it only blinks or looks around now and then while you're using the app. Buki also shows up in the empty session view, Settings → Work memory (it dozes when memory is off), the Fresh with memory dialog and the update dialog. Turn it off under Settings → Features → **Buki**; your stick figure setting and today's counts carry over.
- **고침 / Fixes** — 다른 파일을 보다 돌아오면 보던 위치(스크롤)로 돌아가요. Git 칸을 좁혀도 탭이 다음 줄로 넘어가고 목록이 가로로 넘치지 않아요(긴 브랜치 이름은 …로 줄여요). 설정 → 작업 기억의 크기가 1MB 보다 작으면 "0 MB" 대신 KB 로 보여요. / Files reopen at the scroll position you left them. A narrow Git pane wraps its tabs and no longer scrolls sideways (long branch names are shortened with …). Settings → Work memory shows sizes under 1 MB in KB instead of "0 MB".
